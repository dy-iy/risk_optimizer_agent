# phrasebank 数据集

## 标注任务

**任务类型：金融情感三分类。negative、neutral、positive 分别表示投资者视角的负面、中性、正面情感。**

输入为 `text` 和 `inputs`，输出为 `label`。

## 数据规模与划分

| 文件 | 样本数 | 用途 |
| --- | ---: | --- |
| [train.csv](train.csv) | 1,425 | LF 生成、错误分析、修改与版本选择 |
| [test.csv](test.csv) | 357 | 迭代结束后评估 |
| 合计 | 1,782 | |

复核后的候选池共 2,264 条；按标签下采样删除 482 条多数类样本。
在保持标签覆盖和每侧类别数量最大/最小不超过 3:1 的条件下，保留尽可能多的原始记录；不复制样本、不修改标签。
按标签组合联合分配 train/test，目标约 80%/20%；每个标签及总数允许一个同文本组的整数取整误差。
同文本组不会跨集合；seed 只决定同一标签组合内的稳定选择次序，不随机决定类别配额。原上游划分仅留作来源信息。

这是下采样后的实验子集；测试分布也已均衡化，分数不直接代表原始自然分布或官方评测。

## 标签分布

占比以各集合的样本数为分母；同一条样本中的同名标签只计一次。

### label

| 标签 | 训练数量 | 训练占比 | 测试数量 | 测试占比 |
| --- | ---: | ---: | ---: | ---: |
| negative | 242 | 16.98% | 61 | 17.09% |
| neutral | 726 | 50.95% | 183 | 51.26% |
| positive | 457 | 32.07% | 113 | 31.65% |

train 最大/最小类别数量 = 3.00:1；test 最大/最小类别数量 = 3.00:1。

已有规则曾接触旧训练数据；重新分配后的测试集对这些历史规则仅作兼容性对照，不视为独立泛化评估。
