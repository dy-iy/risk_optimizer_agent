# Financial PhraseBank：投资者视角三分类情感：标注说明

输入为英文金融句子，输出 negative、neutral 或 positive。依据句子明确表达的金融或经营影响判断投资者视角情感；一般情绪词或公司名称不能单独决定标签。注意利润/成本等指标、变化方向、否定、比较基准和转折，不补充句外股价信息。

## 默认标签

negative、neutral、positive

## 数据与评估边界

Macro-F1 严格提升，另报 Accuracy 和每类 P/R/F1。仅使用 cp1252 编码的 AllAgree；四个一致性子集重叠，不合并。默认文本分组划分 train/test 为 80/20。

本文解释任务和 LF 的构造依据，不替代冻结金标或人工确认。原始文件不改写。

迭代、候选接受和重试仅依据训练集；测试集指标只在本次决策完成后写入报告，不反馈模型。
