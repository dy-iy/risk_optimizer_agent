# 加密货币新闻：风险类别与等级联合标注：标注说明

输入为新闻正文，输出 categories（可多选）和 level（low/medium/high）。标签使用 config.json 中的 12 类风险。依据文本事件事实和冻结训练金标判断风险，不能把一般负面语气直接映射为 high。注意已发生事件、条件假设、观点、历史回顾、否认和澄清。数据只有文档级等级，没有单独的类别级等级金标。

## 默认标签

链上漏洞 / 攻击风险、诈骗 / 跑路 / Rug Pull 风险、监管与法律风险、交易所与系统运维风险、稳定币异常风险、爆仓 / 清算风险、大额转账 / 巨鲸行为风险、异常行情波动风险、项目治理 / 团队异常风险、偿付能力 / 储备 / 流动性风险、基础设施 / 协议层异常风险、宏观 / 政策冲击风险

## 数据与评估边界

沿用 v4 的类别 Micro/Macro-F1、等级 Macro-F1、high recall/F1 权重和下降门槛。原 1000 条数据已参与历史迭代，仅作兼容性对照。

本文解释任务和 LF 的构造依据，不替代冻结金标或人工确认。原始文件不改写。

迭代、候选接受和重试仅依据训练集；测试集指标只在本次决策完成后写入报告，不反馈模型。
