# FinCausal Task 1：因果关系存在性二分类：LF 构建方案

0 和 1 各构建一个 LF。正类识别原因与结果间联系；负类识别有依据的非因果结构。不把所有缺少 because 的句子判 0，也不把单个连接词命中当作充分条件。不确定则弃权。

## 公共接口

- 函数为 lf(record)，输入仅包含 text 和 inputs，无 gold、样本 ID 或来源元信息。
- 命中返回 labels、reason；Crypto 另含 level；不命中返回 None。
- 样例来自 train，不通过 ID 或全文记忆作答。
- 生成后先运行并评估，再交给 Analyzer 定位问题；Patcher 只替换选中的现有 LF。
- 不允许修改聚合器、数据加载和评分工具。

## 分析重点

分别分析正类误报与漏报、二分类混淆和 LF 命中质量。检查将时间/相关关系误当因果、以及隐式因果漏报。因果线索列表只辅助分层，不充当金标。

## 接受条件

Macro-F1 严格提升，正类 F1 最大下降 0.02。有标签 trial/practice 合并前检查冲突；当前 3 组同文本冲突共 6 条已全部隔离，未猜测金标。blind evaluation 不评分。

代码或执行失败的候选不接受；版本选择只看 train；本次迭代决策完成后，test 仅用于各脚本的报告评估。
