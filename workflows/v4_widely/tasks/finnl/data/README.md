# finnl 数据集

## 标注任务

**任务类型：17 类金融新闻主题多标签分类。一条新闻可同时属于多个主题。**

输入为 `text` 和 `inputs`，输出为 `labels`。

## 数据规模与划分

| 文件 | 样本数 | 用途 |
| --- | ---: | --- |
| [train.csv](train.csv) | 280 | LF 生成、错误分析、修改与版本选择 |
| [test.csv](test.csv) | 71 | 迭代结束后评估 |
| 合计 | 351 | |

复核后的候选池共 7,758 条；按标签下采样删除 7,407 条多数类样本。
在保持标签覆盖和每侧类别数量最大/最小不超过 3:1 的条件下，保留尽可能多的原始记录；不复制样本、不修改标签。
按标签组合联合分配 train/test，目标约 80%/20%；每个标签及总数允许一个同文本组的整数取整误差。
同文本组不会跨集合；seed 只决定同一标签组合内的稳定选择次序，不随机决定类别配额。原上游划分仅留作来源信息。

这是下采样后的实验子集；测试分布也已均衡化，分数不直接代表原始自然分布或官方评测。

## 标签分布

占比以各集合的样本数为分母；同一条样本中的同名标签只计一次。

多标签按出现次数统计，比例不要求相加为 100%；空标签与非空标签数量另行约束在 3:1 内。
