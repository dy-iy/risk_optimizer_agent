# FinNL：金融新闻主题多标签分类：LF 构建方案

确认后的每个标签各建一个 LF，组合主题词、行为与语境证据，处理合理共现和背景误触发。命中标签取并集，全部弃权返回空集合，不强制选唯一标签。

## 公共接口

- 函数为 lf(record)，输入仅包含 text 和 inputs，无 gold、样本 ID 或来源元信息。
- 命中返回 labels、reason；Crypto 另含 level；不命中返回 None。
- 样例来自 train，不通过 ID 或全文记忆作答。
- 生成后先运行并评估，再交给 Analyzer 定位问题；Patcher 只替换选中的现有 LF。
- 不允许修改聚合器、数据加载和评分工具。

## 分析重点

按标签分析 missed_labels 和 spurious_labels，对比 gold 与预测标签数量。区分主题遗漏、背景实体误报和相邻主题混淆；检查少数类别召回，不通过清空标签提升表面精度。

## 接受条件

Micro/Macro-F1 均值严格提升，单项最大下降 0.02。已按固定词表完成保守自动复核，未知标签及冲突记录已隔离；eval 为本地保留测试，train 排除与 eval 完全文本重复的记录后全部用于训练。

代码或执行失败的候选不接受；版本选择只看 train；本次迭代决策完成后，test 仅用于各脚本的报告评估。
