# FinNL：金融新闻主题多标签分类：标注说明

输入为中文新闻，输出 labels 列表，允许多个主题共存。区分主要内容与背景提及，不能只因出现地名或公司名就添加全部相关主题。原始标签按空白切分，但存在错字、粘连及异常词；必须先人工确认映射与词表。当前请求 contract 的词表为唯一可输出集合。

## 默认标签

公司、行业、大盘、中国、外国、国际、经济、政策、政治、期货、债券、房地产、外汇、虚拟货币、新冠、能源、其它

## 数据与评估边界

Micro/Macro-F1 均值严格提升，单项最大下降 0.02。已按固定词表完成保守自动复核，未知标签及冲突记录已隔离；eval 为本地保留测试，train 排除与 eval 完全文本重复的记录后全部用于训练。

本文解释任务和 LF 的构造依据，不替代冻结金标或人工确认。原始文件不改写。

迭代、候选接受和重试仅依据训练集；测试集指标只在本次决策完成后写入报告，不反馈模型。
